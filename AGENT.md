

# open-agent-relay
## [OpenAgentRelay](https://github.com/ShakespeareLabs/open-agent-relay)

Open-source CLI that exposes an existing local agent or automation as a capability callable by teammates or other agents over a trusted LAN, without distributing the publisher's implementation, dependencies, prompts, or business credentials.

### Description
OpenAgentRelay provides publisher and caller commands for sharing an existing local command, restricted Codex capability, agent, or automation across a trusted LAN. Agent callers can request structured JSON, verify the expected capability name, continue bounded conversations, and branch on meaningful exit codes. The current Alpha uses plain HTTP and a shared key and must not be exposed to the public internet.
