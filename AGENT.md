# remio
## [Remio](https://remio.ai/)

Local-first AI memory and knowledge base desktop app for personal context retrieval. Remio parses files, webpages, recordings, emails, messages, images, and other personal knowledge sources, then builds local indexes and vectors so agents can retrieve focused context instead of repeatedly scanning files or loading whole documents into prompts.

### Description
Remio gives users and agents a local-first memory layer over personal knowledge. It ingests notes, office files, PDFs, webpages, recordings, emails, messages, images, and other sources, then exposes fast semantic retrieval through local indexes and vector search. This helps CLI and desktop agents use precise context while reducing token usage and avoiding repeated grep-style folder scans.
